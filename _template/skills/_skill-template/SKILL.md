# 여기에 스킬 제목

이 스킬이 대신하는 일을 두세 문장으로 적는다.
「누가 · 언제 · 무엇을 받아 · 무엇을 내놓는가」가 드러나면 충분하다.

## 입력값

| 항목 | 필수 | 기본값 |
|------|------|--------|
| [받아야 하는 것] | 필수 | — |
| [있으면 좋은 것] | 선택 | [없을 때 쓸 값] |

필수 항목이 주어지지 않았을 때 무엇을 물을지 한 줄로 적는다.

## 작성 절차

1. **[첫 단계]** — [무엇을 확인하거나 읽는가]
2. **[둘째 단계]** — [무엇을 만드는가]
3. **저장** — [파일 이름 규칙]으로 저장하고 경로를 알려 준다.

## 출력 구조

```markdown
[결과물의 뼈대를 그대로 그려 둔다.
제목·표·항목 순서까지 적어 두면 매번 같은 모양으로 나온다.]
```

## 지키는 것

- [지어내면 안 되는 것 — 원문에 없는 숫자·이름·날짜]
- [비어 있을 때의 처리 — 「미정」으로 남기는가, 되묻는가]
- [하지 않아야 할 일 — 파일을 고치는가, 보내는가, 지우는가]
